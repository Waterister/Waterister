ArcGIS Import Instructions for Geologic Voxel Data
==================================================

Generated Files:
  - simple_test_voxels.nc
  - simple_test_ascii_grids
  - simple_test_points.csv

Import Steps:
1. For NetCDF files (.nc):
   - Use 'Make NetCDF Raster Layer' tool
   - Select appropriate variable (rock_type, porosity, permeability)
   - Set dimension values for 3D visualization

2. For ASCII Grid files (.asc):
   - Use 'ASCII to Raster' tool
   - Import each Z-slice as separate raster layer
   - Use 'Composite Bands' for 3D visualization

3. For Point Cloud CSV files:
   - Use 'XY Table To Point' tool
   - Set X, Y, Z coordinate fields
   - Enable Z-values for 3D visualization

4. Coordinate System:
   - Use coordinate system: EPSG:4326
   - Ensure all layers use the same projection

5. Visualization Tips:
   - Use 3D Scene for better voxel visualization
   - Apply appropriate symbology based on rock types
   - Use transparency for better 3D viewing
